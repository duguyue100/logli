I read Yin Wang's blog few days ago. It's arguing Linux and Windows. Here is my opinion. Windows got some really nice products: Windows 98, Windows XP and Windows 7. Some failed (or strategic) products are really really bad, like Windows Me (first try on NT), Windows Vista and also the latest, Windows 8 (some of KFC in my place are still using Windows me to boot their transaction system). *NIX is a fantastic software, but also an arrogant software. It's so popular is because it always provides a fundamental I/O and file system (not because it's open, only Linux is the fully open-source *NIX operating system). Is Linux stable? Yes, if you are not going to use what we called CJK (Chinese Japanese and Korean), and fortunately, I only use English on my Ubuntu and when I'm trying to type Chinese, I use Google Chrome to cover this problem. Is Windows unstable? Well, products before Windows 7, yes. Windows 7 might be the most fantastic Windows I have ever seen in the whole product line of Microsoft (well, Xbox sounds good too). IDE under Windows is solid and strong. On the other hand, Linux has some powerful editor, but no IDE (well, it's not so fair since Emacs can be configured as IDE, but not as powerful as Visual Studio). But QT is working on that. Eclipse is always a fantastic choice (should be a legendary choice). Windows do have serious advantage on drivers (especially Video drivers for commercial usage). Mac OS sounds like a good design for user. I have never used that, so no comment. But Steven Jobs is a artist more than a programmer. So I'm not expecting so much on professional usages (although many professionals are using MacBook, because it's solid quality?). Programmers have our own culture according to our own belief, just like Christian or Muslim. If you are not, don't even try to distinguish the difference between Windows and Linux. Stay on Windows, you will be fine. For scientific purposes, since scientists are unpredictable, working with Linux might be a better choice and also always have a backup of Windows in case you have to test something. For programming and development, I do think Windows is a better platform. For fun, please go through Mac. For programmers, my basic belief is console is usually better than GUI (not always, for example Google Chrome is a great little thing) and IDE is slightly better than Editor (I was been through the editor period ).
